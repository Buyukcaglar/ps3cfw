First public release: **HDD2TB-P13 (v1.0)**, firmware that lets a launch PS3 (CECHA00) on
Evilnat 4.93 Cobra 8.5 CEX use a 2 TB SATA SSD as its internal drive, including working
file-system repair.

Check the file before you copy it to the USB stick: `certutil -hashfile PS3UPDAT.PUP SHA256`
in a Windows command prompt must print the hash above. `SHA256SUMS.txt` holds the same value.

## Requirements

* **CECHA00 only** (the launch 60 GB model with NAND flash). Never install on any other model.
* **Evilnat 4.93 Cobra 8.5 CEX already installed.** Never install over official (OFW) or hybrid (HFW) firmware.
* A 2 TB-class SATA SSD with 512-byte sectors, at most 2,130,303,778,816 bytes. Tested: Lexar NQ100 2TB,
  PNY 2TB SATA SSD, Crucial BX500 2TB.
* A FAT32 USB stick, and a NAND backup of your console.

## What changed from Evilnat 4.93 Cobra 8.5 CEX

* Drive admission limit raised from 1536 GiB to 1984 GiB (`emer_init`, `sysconf_plugin`).
* Kernel aggregate mount ceiling raised from 128 KiB to 192 KiB, so a 2 TB volume mounts (`lv2_kernel`).
* File-system checker memory raised from 32 MiB to 128 MiB (`sysconf_plugin`).
* Checker error-path fixes for allocation overflow, failed seeks, missing summary buffers and read errors
  (`libfs_utility_init`).
* A small recorder writes a 272-byte memory report (`HDD2TB-P8.bin`) to the USB stick in the rightmost
  port after each full repair. Without a stick it does nothing.

Everything else is unchanged.

## Install

1. Copy the file to the stick as `PS3/UPDATE/PS3UPDAT.PUP`.
2. Shut the console down to standby and put the stick in the **rightmost** USB port.
3. Start Recovery Mode and choose option **6 System Update**. Do not interrupt it.
4. Check *Settings > System Settings > System Information*: version 4.93, free space unchanged.

To fit a new drive afterwards, accept the format offered for the new, empty drive. Expect about
1658 GB free of 1863 GB (PNY, Crucial) or 1698 GB free of 1907 GB (Lexar).
Full instructions, including Recovery Mode timing, data migration and rollback:
[user guide](https://github.com/Buyukcaglar/ps3cfw/blob/main/docs/USER-GUIDE.md).

## Known limits

* 2 TB-class drives only. Larger drives and 4K-native drives are not supported.
* Power loss was tested at an idle XMB, not during heavy writes.
* A long-term soak with monthly repair checks runs until about January 2027.
* Reads run at about 60 MB/s (a console limit). Writes run at about 29 MB/s for the first ~25 GB, then about 12 MB/s.

## Never

* Never choose **Restore PS3 System** or **Format Utility** on a drive that holds data.
* Never install an official Sony update over this firmware.
* Never interrupt a firmware update or a file-system check.

A bad install can brick the console. Recovery then needs a hardware NAND flasher and a NAND backup
of that console. Use at your own risk. Not affiliated with or endorsed by Sony Interactive Entertainment.
